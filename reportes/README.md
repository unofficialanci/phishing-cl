# Reportes

Informes puntuales: un caso o una ola de un actor (qué pasó, a quién afectó,
cronología y recomendaciones). Los IoC siempre viven en [`feeds/`](../feeds/),
[`marcas/`](../marcas/) y [`actores/`](../actores/); aquí va el contexto.

Nombre sugerido: `AAAA-MM-DD-actor-o-marca.md` (p. ej. `2026-11-24-uanci-ph02-metrogas.md`).
