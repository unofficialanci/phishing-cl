# Correcciones y retiro de entradas

Si un dominio de estos feeds es **tuyo y es legítimo**, o el sitio ya fue
limpiado:

1. Abre un *issue* con la plantilla **Solicitar corrección** (título `Corrección: dominio.cl`).
2. Indica por qué es legítimo (o desde cuándo está limpio) y un contacto.
3. Se revisa y, si corresponde, se retira en el siguiente export. El historial
   de git conserva el cambio, por transparencia.

No se publican datos de víctimas. Si ves alguno por error, avisa y se elimina
de inmediato.
